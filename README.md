#  ¿Qué es Angular?

Angular es un **framework** (marco de trabajo completo) de código abierto desarrollado por **Google**.

## Pilares Principales



* **TypeScript:** Lenguaje base (JavaScript con tipado estático) que permite detectar errores antes de la ejecución.
* **Arquitectura basada en Componentes:** La interfaz se divide en piezas pequeñas, independientes y reutilizables.


---

## ¿Qué herramientas necesitan instalar?

Para comenzar  Angular debemos  instalar las siguientes herramientas:

### 1. Node.js y npm
Angular requiere un entorno de ejecución de JavaScript fuera del navegador.
* **Función:** Gestionar dependencias y ejecutar scripts de construcción.


### 2. Angular CLI (Command Line Interface)
Herramienta de línea de comandos esencial para la gestión del ciclo de vida de la aplicación.
* **Función:** Crear proyectos, generar componentes, realizar pruebas y desplegar la aplicación.
* **Comando de instalación global:**
    ```bash
    npm install -g @angular/cli
    ```
* **Verificación:**
    ```bash
    ng version
    ```

---

## Comandos Rápidos

1. **Crear nuevo proyecto:** `ng new nombre-del-proyecto`
2. **Acceder a la carpeta:** `cd nombre-del-proyecto`
3. **Ejecutar servidor local:** `ng serve --open`
